# El Portón de la Condesa — Web & Lead CRM

Proyecto web construido sobre una plantilla Next.js editorial adaptada para El Portón de la Condesa. El objetivo es combinar una experiencia pública orientada a bodas y eventos con un sistema posterior de captación, cualificación y seguimiento de leads.

## Stack base

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Radix UI / shadcn
- React Hook Form / Zod
- Recharts

## Arranque

```bash
npm install
npm run dev
```

Consulta `START_HERE.md` y `project-reference/` antes de comenzar la adaptación con Claude Code.

## Estado

Baseline preparado. La transformación del frontend, backend CRM, persistencia, autenticación administrativa, analítica y documentación final se desarrollarán por fases.
