# Recursos de marca

Recursos preparados a partir del logotipo actual facilitado como referencia del proyecto.

## Archivos

- `logo-porton-current-reference.png`: copia exacta de la referencia recibida.
- `logo-porton-hq.png`: versión PNG de alta resolución 3344×852 con fondo verde oscuro.
- `logo-porton-transparent-hq.png`: versión de alta resolución con fondo transparente.
- `icon-porton-hq.png`: símbolo de la cerradura aislado, fondo transparente, 1024×1024.
- `icon-porton-on-green.png`: símbolo preparado sobre el verde corporativo, 1024×1024.
- `brand-colors.json`: colores principales extraídos del logotipo.

## Uso recomendado

- Header principal: `logo-porton-transparent-hq.png` o `logo-porton-hq.png` según fondo.
- Footer: versión transparente.
- Favicon / app icon / metadata: `icon-porton-hq.png`.
- Open Graph o fondos oscuros: `icon-porton-on-green.png`.

## Colores de referencia

- Verde oscuro: `#182605`
- Rojo coral: `#FF422C`

Claude debe respetar el logotipo como activo de marca y no sustituirlo por texto tipográfico genérico.
